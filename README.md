# COMEX · Prototipo de gestión de importaciones

Proyecto de Marcelo Olea para demostrar el flujo de gestión de órdenes de compra y expedientes de importación.

## Funcionalidades de demostración

- Maestros de productos y clientes, con precios y estado de aprobación.
- Generación automática de una PO desde un maestro aprobado, cantidad y fecha solicitadas.
- Circuito simulado de aprobación, rechazo, revisión y envío de la PO.
- Consulta de expedientes, checklist documental y ficha de importación.
- Carga y descarga temporal de documentos.
- Registro manual de la referencia en MANAGER.

## Alcance del prototipo

La demostración utiliza datos ficticios y permite recorrer las pantallas y el flujo general de operación. Las aprobaciones y los envíos son simulados. Los cambios y archivos cargados se mantienen durante la sesión y se reinician al recargar la página.

Las integraciones empresariales, la persistencia de datos y el análisis automático de documentos corresponden a etapas posteriores del desarrollo.
